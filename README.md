# numengames-repo-template

Starting point for every new Numen Games repository: entry file, license and shared CI hooks.

## After "Use this template"

1. Fill the `TODO` lines in `AGENTS.md` and write this README.
2. Check the license: MIT by default; the engine and the fleet recipe are AGPL-3.0.
3. Settings → Advanced Security → Dependabot alerts: on. A template does not copy settings.
4. Give access to the GitHub Apps that work on it (Ursa's and `numinia-ci-puerta`).
5. Tell Ursa: she adds the repository to Hermes's list (`repos_numen.py`) and to its project.
